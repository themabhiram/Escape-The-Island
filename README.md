# Escape The Island

A Python-based retro text adventure inspired by the eXit game from Mr. Robot, featuring branching choices, survival decisions, and multiple endings.
The game puts you in a dangerous situation where every decision matters. Choose carefully, follow the clues, and try to survive.

## About The Game

You wake up alone on a mysterious island.

Your goal is to find the treasure and escape before nightfall.

Along the way, you will face different paths, dangerous situations, caves, traps, and difficult choices.

Every decision can lead to a different outcome.

**Will you survive or will it be GAME OVER?**

## Inspiration

This project was inspired by the retro-style text adventure game shown in the *Mr. Robot* series, particularly the branching-choice and survival-game concept.

This is an original beginner Python project and is **not affiliated with or endorsed by *Mr. Robot***.

## Features

- Retro-style text adventure
- Multiple story paths
- Branching choices
- Different Game Over outcomes
- Treasure hunt
- Survival-based decisions
- ASCII art introduction
- Terminal-based gameplay
- Beginner-friendly Python code
